# Machine Learning reference

This course builds models from examples and evaluates their behavior on reserved observations. Data Science emphasizes inspecting and communicating data; AI Foundations emphasizes representing problems and reasoning with algorithms such as search. A shared dataset can support different projects, with the question and evidence determining the focus.

## Prerequisites and route

Python lists, functions, loops and CSV fields support the first data-card project. Means and distances support clustering and neighbors. Fractions, probabilities and a fixed feature order support Bayes classification. The first neural exercises develop their arithmetic explicitly.

Check these three small cases before starting: the mean of [2,4,6] is 4; the squared distance between [1,0] and [0,1] is 2; a species column is the target when the four flower measurements are used to predict species. The label stays outside the feature matrix.

Begin with [data inspection](#machine-learning-ml0-setup-tooling-and-data-workflow), then the evaluation contract. Continue through clustering, neighbors, Bayes, shallow trees, regression and the bounded neural comparisons before the [capstone](#machine-learning-ml8-master-project). Image classification and the practice studios are optional follow-ups with their own declared limits.

## References for the actual work

- [pandas CSV loading](https://pandas.pydata.org/docs/reference/api/pandas.read_csv.html): inspect column names, types and missing-value parsing.
- [scikit-learn metrics](https://scikit-learn.org/stable/modules/model_evaluation.html): check a metric's definition, class order and averaging convention.
- [NIST AI RMF](https://www.nist.gov/itl/ai-risk-management-framework): describe intended use, uncertainty and review responsibility.

The local project README and requirements identify the versioned execution contract. The references explain the tools and interpretation; the supplied files and worked examples make the course tasks reproducible.
